# 功能指南

## 🎓 教学工作台

- **课题生成**：输入主题方向，AI 生成多个备选课题（含简介、时长、对象、级别）
- **教学灵感**：围绕主题给教学设计与课堂活动点子
- **内容生成**：按课题撰写讲义/讲稿正文
- **保存成果**：一键导出 DOCX 归档

## 🔬 科研工作台

顶部 Tab 切换功能：

- **学术对话**：带上下文的科研问答，可挂 Dify 知识库
- **论文解读 / 审稿**：粘贴论文全文或上传 PDF，输出结构化解读或审稿意见
- **Arxiv 速览**：粘贴 arxiv 链接自动抓取并解读
- **学术写作**：论文段落生成、趋势分析、期刊推荐
- **文献检索**：OpenAlex / AMiner / Crossref 三库检索 + AI 综合分析

## 📰 每日资讯

- 左侧按分类筛选，右上角切换日期或搜索
- 点「生成」触发当日 RSS 抓取 + AI 摘要
- 点击卡片打开阅读抽屉，可跳转源站

## 📚 知识库

1. 「新建数据集」
2. 点数据集卡片 → 上传文档（PDF/DOCX/TXT/MD）
3. 等待 Dify 引擎完成索引（进度可见）
4. 到对话页工具栏选择该知识库

## 🎬 视频分析

上传视频（mp4 等）→ 后台自动：ffmpeg 抽音频 → 百炼 Paraformer 语音转写 → AI 生成摘要与 5 道 Q&A 闪卡。处理约 1-3 分钟，页面自动轮询结果。

> 失败会如实提示原因（如音频无语音、模型未开通），不会用假数据冒充。

## ✨ 技能中心

浏览/搜索技能卡片，☆ 收藏常用技能；「新建技能」可自定义名称、分类、图标与提示词，保存后立即出现在对话页技能下拉中。
