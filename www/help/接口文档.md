# 接口文档

> 本页为导览；**在线、可调试、与代码实时同步**的完整文档请用下面两个入口。

## 在线文档入口（推荐）

| 入口 | 地址 | 特点 |
|---|---|---|
| **ReDoc** | <https://csic.thinkalike.com.cn/redoc> | 阅读友好，适合查接口 |

> 这三个入口由后端代码**运行时自动生成**——代码更新部署后文档自动同步，永远是最新版。

## 认证

```
Authorization: Bearer <JWT>
```

```bash
curl -X POST https://csic.thinkalike.com.cn/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"用户名","password":"密码"}'
# → {"access_token":"<JWT>","token_type":"bearer"}
```

## 流式对话示例

```
POST /api/chat/dify-chat
{"query":"你的问题","model":"deepseek","conversation_id":"","skill_id":"","kb_id":""}
```

首帧返回 `{"type":"meta","conversation_id":"..."}`，随后 `{"content":"..."}` 增量帧，`[DONE]` 结束。

`model` 可选：`deepseek` / `qwen-plus` / `qwen-max` / `glm-4` / `kimi` / `minimax`

## 错误码

| 码 | 含义 |
|---|---|
| 401 | 未登录 / Token 失效 |
| 403 | 无权限 |
| 422 | 参数缺失或格式错误（响应体含字段位置） |
| 502 | 上游 AI 调用失败（响应体含原因） |
| 503 | 所需 API Key 未配置 |

平台原则：**失败即明示**，不会返回编造的兜底数据。
