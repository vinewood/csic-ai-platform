## 一、认证

除 `/api/auth/login`、`/api/auth/register` 外，所有接口需要请求头：

```
Authorization: Bearer <JWT>
```

JWT 通过登录接口获取：

```bash
curl -X POST https://csic.thinkalike.com.cn/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"用户名","password":"密码"}'
# → {"access_token":"<JWT>","token_type":"bearer"}
```

MCP 接口另支持静态令牌，见 [MCP接入指南.md](./MCP接入指南.md)。

## 三、核心接口用法

### 1. 流式对话（SSE）

```
POST /api/chat/dify-chat
Content-Type: application/json
Authorization: Bearer <JWT>

{"query":"你的问题","model":"deepseek","conversation_id":"","skill_id":"","kb_id":""}
```

- `model`：`deepseek` / `qwen-plus` / `qwen-max` / `glm-4` / `kimi` / `minimax`
- `conversation_id` 留空自动建会话，响应首帧 `{"type":"meta","conversation_id":"..."}` 回传
- 后续帧 `{"content":"..."}`，结束 `data: [DONE]`

### 2. 知识库检索（RAG）

```
GET /api/dify/retrieve?query=关键词&top_k=5
Authorization: Bearer <JWT>
```

返回相关文档片段（来源名 + 内容 + 得分）。

### 3. 学术检索

```
GET /api/academic/openalex/works?query=shipbuilding
GET /api/academic/aminer/scholar?name=张三
GET /api/academic/crossref/search?query=party+school
Authorization: Bearer <JWT>
```

### 4. 每日资讯

```
GET /api/rss/articles?category=科技&date=2026-07-25
Authorization: Bearer <JWT>
```

- 详见 [MCP接入指南.md](./MCP接入指南.md)

## 五、错误码约定

| 码 | 含义 |
|---|---|
| 401 | 未登录或 Token 失效 |
| 403 | 无权限（如非管理员） |
| 422 | 参数校验失败（响应体含缺失字段位置） |
| 502 | 上游 AI 服务调用失败（响应体含原因） |
| 503 | 未配置所需 API Key |

平台原则：**失败即明示**——接口不会返回编造的兜底数据，失败时务必读响应体 `detail` 字段。
