# 中船党校 AI 智能业务系统 —— 需求规划清单 v3.0

> **客户背景**：中船党校（中国船舶集团党校），约 40+ 人使用  
> **核心定位**：集科研辅助 + 教学培训 + 信息聚合 + AI 知识库于一体的党校 AI 智能工作平台  
> **用户角色**：讲师（课件开发/教学）、科研人员（课题研究/论文）、领导（每日新闻阅读）
> **生产环境**：https://csic.thinkalike.com.cn（ECS 39.96.86.119 / 4GB / Ubuntu 26.04）
> **GitHub**：https://github.com/vinewood/csic-ai-platform

---

## 一、系统整体架构

```
┌──────────────────────────────────────────────────────────┐
│                中船党校 AI 智能业务平台                      │
│                   csic.thinkalike.com.cn                   │
├──────────────┬──────────────┬─────────────────────────────┤
│  AI对话      │  教学工作台   │      信息导航台              │
│  (通用)      │  (讲师)      │      (领导)                 │
├──────────────┴──────────────┴─────────────────────────────┤
│           科研工作台 / 技能中心 / 知识库 / 视频分析          │
├──────────────────────────────────────────────────────────┤
│ 系统管理（用户/模型/API/RSS/邮箱）+ 开源项目集成中心          │
├──────────────────────────────────────────────────────────┤
│ 基础设施：ECS Nginx → FastAPI + Docker(Dify+PG+Redis)      │
└──────────────────────────────────────────────────────────┘
```

### 当前技术栈（稳定版，不再重构）

| 层 | 技术 | 说明 |
|----|------|------|
| **前端** | Vue 3 SPA + Vite 8 + Element Plus + Vue Router 5 | 稳定版本，不再重构 |
| **后端** | Python FastAPI + SQLAlchemy 2.0 (async) + SQLite | 直接调用 AI API |
| **AI** | DeepSeek 默认 + 千问/智谱/Kimi/MiniMax/豆包 | 多模型调度 |
| **知识库** | Dify (Docker 5容器) | RAG + 文档解析 + 对话 + 工作流 |
| **部署** | Nginx + systemd + Docker Compose + Let's Encrypt SSL | 自动续期 |

### 集成开源项目全家桶

| 项目 | 部署方式 | 端口 | 用途 | 状态 |
|------|---------|------|------|:----:|
| **Dify** | Docker Compose (5容器) | 5001/3000 | AI 知识库 RAG / 工作流 / 对话 | ✅ |
| **RSSHub** | Node.js 直启 | 1200 | RSS 订阅源生成 | ⏳ |
| **gpt_academic** | Python 引擎 | 8765 | 科研选题生成 / 文献分析 | ⏳ |
| **PostgreSQL** | Docker | 5432 | Dify 数据库 | ✅ |
| **Redis** | Docker | 6379 | Dify 缓存 + 队列 | ✅ |

## 二、核心功能模块（v3.0，2026-07-07）

### 模块一：AI 对话

| 功能点 | 说明 |
|--------|------|
| 多模型接入 | DeepSeek 默认 + 千问/智谱/Kimi/MiniMax/豆包 |
| 单/多模型切换 | 单模型对话 or 多模型对比 |
| SSE 流式响应 | 逐字输出 |
| 技能挂载 | 从技能中心选择，发送时带上系统提示词 |
| 知识库外挂 | 选择 Dify 知识库做 RAG 检索 |
| 附件上传 | 工具栏附件按钮 |
| 对话历史 | 左侧历史列表 |

### 模块二：技能中心

| 功能点 | 说明 |
|--------|------|
| 技能广场 | 14 个预置技能卡片，含图标、分类、描述 |
| 分类筛选 | 科研/教学/新闻/工具 |
| 技能收藏 | 星标收藏/取消 |
| 新建技能 | 自定义名称/描述/提示词 |
| 挂载到 AI 对话 | 点击技能卡片 → 自动跳转对话并挂载 |

### 模块三：科研工作台

| 功能点 | 说明 |
|--------|------|
| 智能选题 | 输入研究方向 → AI 生成 4 个选题 |
| 选题测评 | 四维度评估 |
| 文献检索 | 关键词/标题/作者检索 |
| 内置选题库 | 8 个种子科研选题 |

### 模块四：教学工作台

| 功能点 | 说明 |
|--------|------|
| 课题选题 | AI 生成教学课题 |
| 灵感激发 | AI 生成教学创意 |
| 内容创作 | AI 生成教学大纲/讲稿/课件 |

### 模块五：信息导航台

| 功能点 | 说明 |
|--------|------|
| RSS 源管理 | 20 个内置源按分类管理 |
| 每日资讯 | 分类聚合展示 |
| AI 摘要开关 | 可单独开关 |

### 模块六：系统管理

| 功能点 | 说明 |
|--------|------|
| 用户管理 | 增删改查，4 角色 |
| 模型管理 | API Key 统一配置 |
| RSS/邮箱/API | 统一配置中心 |
| 集成状态 | Dify/RSSHub/gpt_academic 在线面板 |
| 仅 admin | get_admin_user() 中间件 |

## 六、部署架构

```
ECS 39.96.86.119 (4GB, Ubuntu 26.04)
│
├── Nginx :80/:443
│   ├── / → www/index.html (Vue SPA)
│   ├── /api/ → proxy 127.0.0.1:8000 (FastAPI)
│   └── SSL → certbot auto-renew
│
├── csic-backend (systemd, 开机自启)
│   └── uvicorn app.main:app --host 127.0.0.1 --port 8000
│
└── Docker Compose (restart: always)
    ├── dify-api :5001
    ├── dify-db (PostgreSQL)
    ├── dify-redis
    ├── dify-worker
    └── dify-web :3000
```
