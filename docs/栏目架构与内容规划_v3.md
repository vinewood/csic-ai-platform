## 〇、设计规范升级

### 0.1 图标系统

| 项 | 选择 |
|----|------|
| **图标库** | Lucide Icons（MIT 开源，1400+ 线性图标） |
| **风格** | 全部线性（stroke-width: 2px），无填充 |
| **尺寸规范** | Topbar 18px / 卡片 22px / 功能入口 28px / Hero 装饰 48px |
| **颜色规则** | 跟随父元素 `currentColor`，活跃态使用品牌色 |

### 0.2 模型列表（阿里云百炼 MaaS + 第三方 API）

| # | 模型名称 | 品牌色 | API 来源 | 适用场景 |
|---|---------|--------|---------|---------|
| 1 | **通义千问 Qwen-Max** | `#0070CC` | 阿里云百炼 | 主力模型，复杂推理 |
| 2 | **通义千问 Qwen-Plus** | `#3B8CFF` | 阿里云百炼 | 日常对话，成本优化 |
| 3 | **智谱 GLM-4** | `#5B4CC4` | 智谱 API | 长文本处理 |
| 4 | **Kimi (Moonshot)** | `#8B5CF6` | Moonshot API | 超长上下文 |
| 5 | **MiniMax abab6.5** | `#10B981` | MiniMax API | 创意写作 |
| 6 | **DeepSeek V3** | `#4A6CF7` | DeepSeek API | 深度推理 |

> 最多支持 **6 模型同时并行输出**，用户可自由勾选 1-6 个模型。
