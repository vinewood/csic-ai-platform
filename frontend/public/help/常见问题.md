# 常见问题（FAQ）

## 登录与账号

**Q：忘记密码怎么办？**
找系统管理员在「系统管理 → 用户管理」重置；新密码为随机初始密码，仅显示一次，请立即保存并登录后修改。

**Q：注册后无法登录？**
账号需要管理员审批通过后才能使用，请联系管理员。

## 对话与模型

**Q：提示"未配置 XX API Key"？**
该模型对应的服务商 Key 未配置。管理员在「系统管理 → API 配置」中填入即可。

**Q：宫格对比里某个模型一直转圈/报错？**
单个区块失败不影响其他模型。常见原因：该模型 Key 未配置、额度用尽或模型名未开通，错误会直接显示在区块内。

**Q：多模型历史对话为什么显示成单模型？**
宫格功能是 v3.1 上线的，更早的历史记录没有模型标记，按单模型视图回放，属正常现象。

## 知识库

**Q：上传文档后对话检索不到？**
文档需要完成索引（数据集详情里看进度）。索引完成后在对话工具栏**选择该知识库**再提问。

## 视频分析

**Q：视频处理失败"转写失败"？**
常见原因：视频无清晰人声、音频轨缺失。目前 ASR 使用百炼 Paraformer 模型，超长视频可能受限，建议先剪成 10 分钟以内片段。

## 接口与 MCP

**Q：curl 调接口中文乱码 / 报 400？**
Windows 终端会把行内中文转成 GBK。把 JSON 写入 UTF-8 文件，用 `--data-binary @file` 发送。

**Q：MCP 连接报 401？**
检查 Bearer 令牌：JWT 会过期，长期对接请使用 MCP 静态令牌（管理员在服务器 api_configs 的 mcp 记录中查看）。

**Q：接口文档是最新的吗？**
是。`/redoc`、`/docs`、`/openapi.json` 由后端代码运行时自动生成，代码部署即同步。

## 其他

**Q：页面样式/功能没更新？**
强制刷新：`Ctrl + F5`（Mac：`Cmd + Shift + R`）。
