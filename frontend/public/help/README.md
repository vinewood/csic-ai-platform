# 中船党校 AI 助手 · 帮助中心

> 面向党校科研教学场景的一体化智能工作平台
> 本站地址：<https://csic.thinkalike.com.cn>

## 平台能做什么

| 模块 | 一句话说明 |
|---|---|
| 💬 AI 对话 | 多模型对话，点选 2-6 个模型自动宫格同屏对比 |
| 🎓 教学工作台 | 课题生成、教学灵感、内容撰写、成果导出 |
| 🔬 科研工作台 | 学术对话、论文解读/审稿、趋势分析、期刊推荐 |
| 📰 每日资讯 | RSS 聚合 + AI 摘要的行业日报 |
| 📚 知识库 | 文档上传灌库，对话时挂载检索增强（RAG） |
| ✨ 技能中心 | 预置 + 自定义 AI 技能，一键挂载到对话 |
| 🎬 视频分析 | 上传视频自动转写、生成摘要与知识闪卡 |
| ⚙️ 系统管理 | 用户、模型、API Key、用量、开放接口管理 |

## 新手三步

1. **登录** — 使用管理员分配的账号登录平台
2. **对话** — 进入「AI 对话」，顶部点选模型（选 2 个以上自动进入宫格对比）
3. **挂载知识** — 在「知识库」上传文档，对话时选择该知识库即获得检索增强回答
